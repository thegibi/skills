# Ecommerce Retention

## Objective

Increase profitable customer lifetime value after the first purchase.

## Core metrics

- repeat-purchase-rate;
- purchase-frequency;
- AOV;
- LTV;
- gross profit/customer;
- time to second purchase;
- refund/return rate.

## Retention levers

- post-purchase education;
- product usage support;
- replenishment;
- cross-sell;
- upsell;
- loyalty;
- email;
- WhatsApp;
- win-back;
- referral.

## Workflow

1. segment first-time vs repeat customers;
2. build purchase cohorts;
3. identify second-purchase gap;
4. identify product-specific reorder patterns;
5. find retention friction;
6. create lifecycle interventions;
7. measure incremental repeat purchase and gross profit.
