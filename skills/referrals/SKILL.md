# Ecommerce Referrals

## Program types

- customer referral;
- affiliate;
- ambassador;
- creator;
- refer-a-friend;
- referral coupon.

## Evaluate

- referral participation;
- referred customers;
- referral CAC;
- referral conversion;
- revenue;
- gross profit;
- referred-customer LTV;
- incentive cost.

## Workflow

1. define program objective;
2. define eligible referrer;
3. choose incentive;
4. protect margin;
5. define attribution;
6. launch bounded test;
7. compare referred vs non-referred customer quality.
