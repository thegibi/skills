# Ecommerce Email Marketing

## Objective

Move leads and customers toward purchase, repeat purchase, and stronger lifetime value.

## Core flows

- welcome;
- lead nurture;
- browse abandonment;
- cart abandonment;
- checkout abandonment;
- post-purchase;
- product education;
- cross-sell;
- upsell;
- review request;
- replenishment;
- repeat purchase;
- win-back;
- VIP;
- seasonal.

## Principles

- one email, one primary job;
- relevance over volume;
- segment by lifecycle stage;
- value before repeated asks;
- measure revenue and gross profit, not opens alone.

## Workflow

1. identify trigger;
2. identify lifecycle stage;
3. define sequence goal;
4. build message sequence;
5. define delays;
6. define CTA;
7. define conversion event;
8. measure downstream economics.
