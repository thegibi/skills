# AI Agent Skills

A collection of reusable AI agent skills for Cursor, Codex, and other agentic environments.

## Available Skills

### CFO / Business Analyst Agent

A business decision-making skill that turns core operating and financial metrics into structured diagnoses, hypotheses, priorities, and next actions.

**Metrics covered:** ROI, CAC, AOV, Runway, Churn, MRR, and EBITDA.

Path:

```text
cfo-business-analyst-agent/SKILL.md
```

## Repository structure

```text
skills/
├── README.md
└── cfo-business-analyst-agent/
    ├── README.md
    └── SKILL.md
```

## Usage

Point your AI agent to `cfo-business-analyst-agent/SKILL.md`, or copy that directory into the skills location supported by your agent environment.
